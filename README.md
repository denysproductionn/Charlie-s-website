# Charlie's Website 🐶

A simple practice website built with HTML, CSS and a little bit of JavaScript as a homework project. It is a humorous "resume" of Charlie, a professional socks destroyer.

## Pages

- **Main page (`index.html`)**: Charlie's resume with photo, description, skills list and an interactive "like" button
- **Contacts (`pages/contact.html`)**: contact links (LinkedIn, email, treats)
- **Gallery (`pages/gallery.html`)**: "Professional gallery" with 5 photos

## Technologies

- HTML5
- CSS3 (Flexbox, custom styles, SVG background pattern)
- JavaScript (button click handler, message with timeout)

## Project structure

```
Charlie-s-website/
├── index.html
├── styles.css
├── pages/
│   ├── contact.html
│   └── gallery.html
└── photo/
    └── (images)
```

## How to run

1. Clone the repository: `git clone https://github.com/denysproductionn/Charlie-s-website.git`
2. Open `index.html` in any browser

## What I practiced

- Page layout and structure with semantic tags
- Styling and positioning with CSS
- Navigation between multiple pages
- Basic DOM manipulation with JavaScript
